# Global Presence

A Flask-based web application for an immigration and visa consultancy platform.

The project provides information about immigration services and allows users to submit an inquiry through an online assessment form.

---

## Features

- Responsive immigration consultancy website
- Online inquiry / assessment form
- Form validation
- Email validation
- 10-digit phone number validation
- Inquiry data storage using SQLite
- Admin dashboard to view submitted inquiries
- AJAX form submission
- Success and error messages
- Responsive navigation
- Reusable Flask/Jinja components

---

## Tech Stack

### Backend

- Python
- Flask
- SQLite

### Frontend

- HTML5
- CSS3
- JavaScript
- Jinja2 Templates
